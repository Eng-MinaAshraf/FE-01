# AI Assistant Guidelines

## Tech Stack
- **Environment**: Node.js
- **Version Control**: Git / GitHub
- **Languages**: JavaScript / HTML / CSS (to be expanded)

## Coding Conventions
1. Follow standard JavaScript conventions.
2. Use descriptive variable and function names.
3. Keep functions small and single-purpose.
4. Add comments for complex logic.
5. All commits must follow the **Conventional Commits** specification (`feat:`, `fix:`, `docs:`, `chore:`, etc.).
